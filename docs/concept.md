# コンセプトとターゲット / UX 原則

## 1. 目的と差別化軸

- **コアコンセプト**: 「あの子」の生後表現(月齢/週齢/累計日/誕生日CD/干支/生年月日)を **書類記入時にスクロール無し・タップ無しで即時参照**、必要なら **タップ 1 つでクリップボードコピー** できる、その用途だけに特化した PWA
- **アプリ名**: 「命の時計」(英語識別子: life-clock)
- **タグライン**: 「あの子の生後を、ぱっと見る」 — 子・孫・甥姪・友達の子・ペットまで対応
- **想定ユースケース**: 母子手帳・予防接種問診票・保育園入園書類・医療機関問診票への生後表現記入、家族の年齢確認、ペットの月齢確認

### 差別化軸(5 点)

1. **全表記 1 画面同時表示**(暦・生年月日(西暦+和暦)・週・累計日・誕生日CD・干支・任意イベント)
2. **数値タップでクリップボードコピー** + **長押しで形式選択**(西暦/和暦/スラッシュ/ハイフン 等)
3. **PWA**(ストア不要、URL 共有でインストール、iOS/Android/PC 横断、オフライン動作)
4. **ログイン不要・広告なし・データはローカル**(家族プライバシー)
5. **複数対象対応**(子/ペット/友達の子 などをタグで色分け、最大数十件)

### 競合認識

- ぴよログ/みてねは「目的が違う」(育児記録/写真共有 ≠ 即時参照)
- 真の競合は「生後カレンダー」「ベビーカレンダー」等の特化アプリ群
- それらに対する優位は **同時表示 + タップコピー + 長押し形式選択 + PWA + 複数対応(タグ色分け)**

## 2. ターゲットユーザ

- **主**: 子を持つ夫婦両方(父・母)
- **副**: 祖父母世代、おじ/おば(URL 共有でホーム画面追加して使う)
- **拡張**: ペットの飼い主、友達の子の月齢を覚えていたい人(タグ機能で対応)
- IT リテラシー前提: 中(夫婦の少なくとも片方は普通にスマホ操作可能)
- → 設定 UI は **隠さない**(右上歯車で通常配置)

## 3. UX 原則

- **メイン画面はダッシュボード型**(全カード並列、メインの「生まれてから」のみ固定で最上段)
- **数値ブロックはすべてタップでコピー** → 1.5 秒トースト + 該当カードに 700ms フラッシュ
- **長押し**(0.6s)で **コピー形式選択モーダル**(西暦/和暦/区切り変更 等)
- **設定 UI は右上歯車から**(子削除・全クリアは 2 段階確認)
- **初回はオンボーディング強制**(子の名前 + 出生日 + タグ任意)
- **複数対象は子切替タブ + 画面水平スワイプ**(2 人以上で有効、アクティブタブが常に中央寄せ)
- **未来日付対応**: 出生日 > 今日 のとき「生まれるまで」モード(妊娠中の予定日にも対応)
- **誕生日当日(1 歳以上の毎年)** はメインカードに「🎂 今日は誕生日!」バッジで祝福
- **Canvas / グリッド表現は使わない**(time-stack の世界観は流用しない)
