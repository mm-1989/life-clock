# 命の時計 (life-clock)

> あの子の生後を、ぱっと見る。

書類記入時に「月齢/週齢/累計日/誕生日カウントダウン/干支/生年月日」を **1 画面で同時参照**、必要なら **タップ 1 つでクリップボードコピー** できる、その用途だけに特化した PWA。

子・孫・甥姪・友達の子・ペットまで、タグで色分けして複数登録できます。

## 主な機能

- 📅 **全表記を 1 画面で**: 暦・週・累計日・誕生日CD・干支・生年月日(西暦+和暦+曜日)
- 👆 **タップでコピー**: 数値カードをタップでクリップボードへ。長押しで形式選択(西暦/和暦/`/区切り`/ハイフン 等)
- 👶 **複数対象対応**: 子・親戚・友達の子・ペットを **タグで色分け**(🏠 家族 / 🌳 親戚 / 🤝 友達 / 🐾 ペット / 🏷️ その他)
- 🤰 **未来日付対応**: 出産予定日にも対応(「生まれるまで N か月」「生まれる予定日」「あと N 週と D 日」)
- 🎂 **誕生日当日の祝福**: 1 歳以降の毎年の誕生日にバッジ表示
- 📝 **任意イベント**: 「最後に会った日」「初めて歩いた日」など自由に登録、「あれから N 日」表示
- 🎛️ **カードの並び替え + 表示/非表示**: 設定モーダルから自由にカスタマイズ
- 💾 **JSON バックアップ/復元**: 機種変や夫婦間でのデータ移行に
- 🌙 **ダークモード**: OS 設定に自動追従
- 📦 **オフライン動作**: PWA(Service Worker + SWR)、ホーム画面追加でアプリ風起動
- 🔒 **データはこの端末のみ**: ログイン不要・広告なし・外部送信なし

## アプリを使う

公開 URL でアクセス → ブラウザの「ホーム画面に追加」 でアプリ風に常駐します。

- iOS Safari: 共有 → ホーム画面に追加
- Android Chrome: メニュー → アプリをインストール
- PC: アドレスバー右の ⊕ アイコンからインストール

入力した出生日・名前・イベントは **この端末の localStorage にのみ保存** され、外部に送信されません。

## 元号対応範囲

大化(645)〜令和まで網羅。歴史上の人物の生年月日でも和暦表示できます。

```
1900-05-12 → 1900年(明治33年)5月12日(土)
1925-08-20 → 1925年(大正14年)8月20日(木)
1989-01-08 → 1989年(平成元年)1月8日(日)
2019-05-01 → 2019年(令和元年)5月1日(水)
2023-05-12 → 2023年(令和5年)5月12日(金)
```

※ 古代〜中世の改元日は概算値の場合があります(精密な歴史考証が必要な用途には別途検証してください)。

## 開発

### 必要環境

- Node.js 20+
- npm

### セットアップ

```bash
npm install
```

`npm install` がハングする場合は `--prefer-offline --no-audit --no-fund` を付けて再試行してください(初回ダウンロードで詰まることがある WSL 環境向けの対処)。

### 開発コマンド

| コマンド | 用途 |
| --- | --- |
| `npm run dev` | 開発サーバ(`http://localhost:5173/life-clock/`) |
| `npm test` | vitest で純関数テスト |
| `npm run typecheck` | TypeScript 型チェック |
| `npm run build` | 本番ビルド(`dist/`) |
| `npm run preview` | ビルド成果物のローカル確認 |

コミット前は **`typecheck` / `test` / `build` の 3 点セット** を通してください。

### 技術スタック

- Vite 6 / TypeScript strict
- HTML + CSS のみ(Canvas/Three.js 不採用)
- localStorage(`lifeClock.v1`)
- vitest(純関数テスト)
- PWA(manifest.webmanifest + Service Worker、SWR キャッシュ戦略)

詳細な設計方針・編集者向けルールは [`CLAUDE.md`](./CLAUDE.md) を参照。

### デプロイ

`main` ブランチへ push すると `.github/workflows/deploy.yml` が走り、GitHub Pages へ自動 deploy されます(`typecheck/test/build` を CI でも強制)。

GitHub Pages の Source は **GitHub Actions** に設定してください(Settings → Pages)。
